# Voice Card Builder

A free browser tool that helps you build a **voice card**: a short document you give your AI assistant (Copilot, ChatGPT, Claude, Gemini) so its drafts sound like you, not like generic AI.

Made by [Colin Young](https://colinyoung.es), communication trainer and coach.

## Privacy
Everything happens in your browser. The page has no server, no accounts and no tracking. A Content-Security-Policy stops the page from loading or sending anything over the network, so the browser itself blocks any attempt to send what you type.

## Status
In testing with participants. Not announced yet, so the page asks search engines not to index it.

## Files
- `index.html`: the whole tool (markup, styles and logic in one file).
